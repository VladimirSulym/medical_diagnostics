# Medical Diagnostics

Medical Diagnostics - это веб-приложение для медицинской клиники, которое позволяет пациентам записываться на прием к врачам, просматривать результаты диагностики и управлять своими медицинскими данными.

## Обзор проекта

Проект представляет собой полноценную систему управления медицинской клиникой с следующими возможностями:
- Управление пациентами и врачами
- Запись на прием к специалистам
- Ведение расписания врачей
- Управление медицинскими услугами
- Хранение результатов диагностики
- Система отзывов о врачах и услугах

## Основные функции

### Для всех пользователей
- Просмотр информации о клинике
- Просмотр списка врачей и их специализаций
- Просмотр доступных услуг
- Регистрация в системе
- Отправка сообщений через форму обратной связи

### Для авторизованных пользователей
- Запись на прием к врачу
- Просмотр истории своих приемов
- Просмотр результатов диагностики
- Управление личным профилем
- Заполнение медицинской анкеты
- Оставление отзывов о врачах и услугах
- Оплата услуг

### Для администраторов
- Управление пользователями
- Управление врачами и их расписанием
- Управление услугами и отделениями
- Просмотр и редактирование всех записей на прием
- Доступ к результатам диагностики
- Управление системой в целом

## Установка и запуск

### Предварительные требования
- Docker и Docker Compose
- Git

### Локальная разработка

1. Клонировать репозиторий:
```bash
git clone https://github.com/yourusername/medical_diagnostics.git
cd medical_diagnostics
```

2. Создать файл .env с необходимыми переменными окружения:
```
SECRET_KEY=your-secret-key
DEBUG=True

CSU_PASS=your-admin-password

# Конфигурация базы данных
DATABASE_NAME=medical_diagnostics
DATABASE_USER=postgres
DATABASE_PASSWORD=your-db-password
DATABASE_HOST=db
DATABASE_PORT=5432

# Конфигурация почты
EMAIL_HOST=smtp.your-email-provider.com
EMAIL_HOST_USER=your-email@example.com
EMAIL_HOST_PASSWORD=your-email-password
EMAIL_PORT=465
EMAIL_USE_SSL=True

POSTGRES_DB=medical_diagnostics
POSTGRES_USER=postgres
POSTGRES_PASSWORD=your-db-password
DJANGO_SETTINGS_MODULE=config.settings
```

3. Запустить проект с помощью Docker Compose:
```bash
docker-compose up -d
```

4. Приложение будет доступно по адресу http://localhost:80

### Запуск через CI/CD

Проект настроен на автоматический деплой при пуше в ветку `develop`. Процесс CI/CD включает следующие этапы:

1. **Lint**: Проверка кода с помощью Flake8
2. **Build**: Сборка Docker-образа и публикация в Docker Hub
3. **Deploy**: Деплой на сервер

Для настройки CI/CD необходимо добавить следующие секреты в GitHub:
- `DATABASE_NAME`, `DATABASE_USER`, `DATABASE_PASSWORD` - данные для подключения к базе данных
- `SECRET_KEY` - секретный ключ Django
- `DEBUG` - режим отладки
- `DOCKER_HUB_USERNAME` - имя пользователя Docker Hub
- `DOCKER_HUB_ACCESS_TOKEN` - токен доступа Docker Hub
- `SERVER_HOST` - адрес сервера для деплоя
- `SERVER_USERNAME` - имя пользователя на сервере
- `SSH_PRIVATE_KEY` - приватный SSH-ключ для доступа к серверу

## Суперпользователь

При запуске проекта через Docker Compose автоматически создается суперпользователь с помощью команды `python manage.py csu`. Учетные данные суперпользователя:
- Email: значение из переменной окружения `EMAIL_HOST_USER`
- Пароль: значение из переменной окружения `CSU_PASS`

Этот суперпользователь имеет полный доступ к административной панели Django и всем функциям системы.

## Структура проекта

- `config/` - настройки Django-проекта
- `users/` - приложение для управления пользователями
- `services/` - приложение для управления услугами и записями на прием
- `templates/` - HTML-шаблоны
- `static/` - статические файлы (CSS, JavaScript)
- `media/` - загружаемые пользователями файлы
- `.github/workflows/` - конфигурация GitHub Actions для CI/CD
